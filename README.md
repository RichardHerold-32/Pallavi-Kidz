# Pallavi Kidz - Multi-Location Preschool Website

Production-ready multi-location preschool website template built with Next.js 14, React 18, and Tailwind CSS.

## About

This template supports dynamic branch pages for 20–25 preschool branches under one brand — **Pallavi Kidz**.

## Tech Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
